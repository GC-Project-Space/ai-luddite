# 참가자 기록

주간 사례 원문과 토론은 GitHub Issue에 남깁니다. 이 디렉터리는 각 참가자가
원할 때 개인 회고를 이어서 기록하기 위한 공간입니다.

## 디렉터리 규칙

GitHub ID를 디렉터리 이름으로 사용하고, 주차별 파일을 그 아래에 둡니다.

```text
members/
└── <github-id>/
    ├── week-01.md
    ├── week-02.md
    └── ...
```

- 디렉터리: `members/<github-id>/`
- 파일: `week-NN.md`
- 주차 번호: 정규 스터디 기준 두 자리 숫자 (`week-01.md`부터
  `week-06.md`까지)

참가자 이름이나 개인 디렉터리는 미리 만들지 않습니다. 첫 기록을 남기는
사람이 자신의 GitHub ID로 디렉터리를 생성합니다.

## 작성 방법

1. [`templates/retrospective.md`](../templates/retrospective.md)를 복사하거나
   자유로운 형식으로 문서를 시작합니다.
2. 문서 상단에 해당 주차와 원본 Issue 링크를 남깁니다.
3. 토론 후 달라진 생각, 아직 풀리지 않은 질문, 다음에 시도할 행동을
   필요한 만큼 기록합니다.
4. 민감 정보, 비밀키, 고객 또는 회사의 식별 가능한 정보가 포함되지
   않았는지 확인합니다.

개인 회고는 선택 사항이며 공동 회고나 통합 회의록을 대신하지 않습니다.
저장소에서는 별도의 공동 회고를 운영하지 않습니다.
